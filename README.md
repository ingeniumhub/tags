# tags

Ejemplos y simulaciones de marcadores fiduciales (AprilTag y ArUco) en robots, con OpenCV y ROS 2.

Acompaña a [Fiduciales en robótica](https://ingeniumhub.org/es/herramientas/generador-de-tags), donde está la explicación completa y un generador para imprimir marcadores a tamaño real.
