# tags

AprilTag y ArUco en robots: detectarlos, estimar la pose y usarla para acoplarse, localizarse, calibrar y manipular. Ejemplos sin ROS y con ROS 2, en simulación y en hardware barato, cada uno con su medición de error.

Es el código que acompaña al [generador de AprilTag y ArUco](https://ingeniumhub.org/es/herramientas/generador-de-tags) de Ingenium Hub: los marcadores salen de ahí, y la página explica la teoría, las estrategias de colocación y los casos reales en los que se basan los ejemplos.

*AprilTag and ArUco markers in robots: detection, pose estimation and use for docking, localization, calibration and manipulation. Examples without ROS and with ROS 2, in simulation and on low-cost hardware, each with its own error measurement. Companion repo to the Ingenium Hub tag generator. Docs in Spanish; code and comments in English.*
